# ai-care-measurement

Measuring whether an AI care chat actually helps telehealth patients, and separating what the chat *does* from *who chooses to use it*.

## Why it's hard

Higher-risk patients use the chat more often (self-selection), and they also have worse outcomes. A naive comparison of chat users and non-users mixes up the chat's effect with the effect of being a sicker patient.

## Data

Synthetic, generated by [`src/generate_data.py`](src/generate_data.py) (fixed seed, so it can be reproduced exactly):

| Table | Grain | Columns |
|---|---|---|
| `patients` | one row per patient (20,000) | patient_id, signup_date, program (weight / hair / bp), plan, baseline_risk |
| `conversations` | one row per AI chat (~83k) | conversation_id, patient_id, started_at, intent, confidence, escalated, escalation_type, resolved, csat |

Built-in features to account for:
- **Self-selection:** risk raises both the chance of using chat and how often.
- **Escalation threshold:** confidence below 0.50 is always escalated to a human (can support a regression discontinuity design).
- **Non-random CSAT missingness:** patients with very good or very bad experiences answer the survey more often.
